## 反例与复核结论

- 未知版本、未知字段、ID 命名空间错误、字符串版本／不安全整数均被拒绝，并保留错误字段路径。
- workflow／invocation 混用字段或尝试 ID 被拒绝；不同宿主、旧 epoch、替换 activation／grant、过期／未生效、延长期限、额外资源或读权限升级为写均被拒绝。
- 缺失 If-Match 为 428；弱 ETag、多值、非当前 ETag 为 412；旧业务内容版本或不同审查 hash 为 409。调用顺序明确要求先认证、权限及去重，再校验新操作。
- 正文／项目名／标题实测 emoji 的 Unicode 边界；附件超过 3 个拒绝。工作数超过 30 或携带 JS 判定器拒绝。
- A2A completed 不属于 Attempt 成功状态；测试失败报告可以合法保存；不同 SHA 的测试／构建／预览引用拒绝；token 增量不能解析成持久事件。
- 测试发现递归 JSON Schema 的 `$defs` 嵌入 OpenAPI 后引用根错误，已修复为组件绝对 JSON Pointer；所有本地引用及生成一致性通过。浏览器可复用的 neutral 构建实际输出 `.js`／`.d.ts`，exports 按实测修正。
- 复核 schema 与设计章节、守卫输入信任边界、生成源码、声明类型、正反样例、失败结果与日志证据；未发现阻止 P0-02 完成的问题。
