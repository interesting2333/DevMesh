## Implemented local behavior

策略冻结批准命令／镜像、报告格式与生产侧、测试身份及需求映射、业务 glob、排除理由和最低 80/70。独立计算入口要求完整 Git 文件清单以及单独固定的完整插桩位置；调用方不能只上传有命中文件。结果保存逐项 PASS／FAIL／MISSING／STALE／N/A／人工 PENDING。执行失败即使有完整报告也保持失败，但保留可解释的原失败数量；未知作业不推定成功。

报告先检查原执行、输出路径、精确字节大小／SHA 和代码／配置，再以有界 UTF-8／JSON 解析；拒绝重复 JSON 键、超深／超大正文、非法位置、计数／位置错配和不明确路径。覆盖按源码路径及完整位置身份合并，数字 ID 不作全局身份，共享源码只计算一次分母。行用 statement start.line 去重，任一同一行 statement 命中即可覆盖；分支按类型／原位置／备选位置和序号固定，隐式 else 无位置保留为明确分支。阈值交叉相乘，不平均百分比或四舍五入放行。

原测试报告解析按真实断言与必要测试身份计算，不以 success／自报百分比／汇总计数代替原事实。失败、跳过、遗漏、运行时错误、重复身份、错 SHA／配置、命令／镜像漂移、缺必要生产侧、遗漏未执行文件、空业务范围、零分支允许／拒绝和位置矛盾均有实际用例。
