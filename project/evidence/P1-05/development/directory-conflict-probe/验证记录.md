# 不重叠路径的真实目录重命名冲突探测

独立临时 Git 仓库中，A 将 old/a 移至 new/a；B 在相同起点新增 old/b 与 new/b。实际 diff-tree 的路径集合互不重叠；merge-tree 返回退出码 1、CONFLICT (file in way of directory rename)，消息涉及 new/b 和 old/b，无 stage 条目。probe.json 保留真实 SHA、原始 NUL 输出、路径及临时根，probe.mjs.txt 保留可重跑的固定命令。

这是后续冲突夹具的可行性探测，只运行 Git，不代表当前计划资格、持久集成、内容引用 ACK、Runner 或产品验收通过。3.1／3.2 不据此勾选。
