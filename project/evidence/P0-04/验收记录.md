## 故障与边界复核

- 流中断、大小／哈希错误、容量不足不形成成功引用；并发同键和同 hash 发布不覆盖既有字节。
- 真实 SIGKILL 切在 stage、发布、索引提交三个位置：staging 不自动收养；已发布正文按原写入恢复；提交后重发仅有一条消息。
- 实际 SQLite trigger 中断消息提交：内容及业务引用同事务回滚，发布字节保留，移除测试故障后原操作恢复一次。
- 会话一 Attempt 一个；消息及步骤顺序、角色／上下文来源、跨 Run 外键与不可变字段有正反例；SENT 未响应保留事实，不推断模型回复。
- 按业务引用和主体读取，同 hash 不授予权限；缺失／损坏正文标 MISSING，JSONL 编辑不改变权威历史，删除视图可重建。
- 显式删除维护原语检查实际外键和读取 pin，DELETING 阻止新引用。自动 GC／保留策略、完整 Runner workspace、全平台备份恢复仍按后续工作包实现。

复核覆盖路径、链接／junction、布局初始化及 storeId、文件刷新和发布顺序、事务内无 await／文件 IO、崩溃恢复、授权入口、私密模型字段拒绝、消息／上下文来源、Worker 关闭与锁释放。未发现阻止本工作包完成的问题。
