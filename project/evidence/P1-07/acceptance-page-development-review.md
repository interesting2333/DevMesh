# P1-07 接受React页面开发复核

候选审查可进入准确接受页面和当前成员保护的本地React脚本。固定SHA、manifest／review／dataPlan摘要和原／当前接受指针，INITIAL空／演示、保留迁移材料及替换来源分别展示。REPLACE独立确认，准备与最终接受分别勾选；刷新、切换原准备或失败清除同意。原历史20项游标，未派发关闭与已派发有理由撤销分开；ABORTING只确认决定已记录，清理待核实。最终提交固定选中原准备及观察，原接受成功与当前发布分开，并连接原Release与导出。

## 验证

最终页面／原HTTP入口6/6、输入组合／审查／契约22/22、接受意图／就绪／T5／撤销与dataset所有权54项、实际Edge接受页面4/4及原审查页面4/4，共90通过、0跳过。构建、类型、Lint、契约一致性通过；整页投影修正后重新构建完整workspace（含Node及三个浏览器单入口），生产源码／产物及其余测试与最终构建一致；构建后仅独立v37迁移测试修正历史SQL设置，针对性3/3复测，最终Lint／Edge重跑。原扩展组整体失败（52通过2失败），其中51个原接受用例通过并按明确范围复用；原组输入差异及未导入该独立测试的MJS闭包均附SHA评估；300条源码映射含新TSX和第三方逐字节匹配，绑定657份源码／产物。迁移1～44和Runner未改。

实际本地HTML／脚本验证当前成员、撤权404、无身份401、查询多字段422、未知候选404、nonce CSP／no-store／nosniff、无配置可读但新动作关闭、GET不准备或预检材料。Edge先明确准备但不接受，分别在真实服务提交后主动丢弃准备和T5的HTTP应答；重载不自动POST，用户点击原请求恢复使用同一键／正文／If-Match，只一个准备和Release／发布Outbox。重开文件型Worker、禁止新材料读取后仍恢复原T5；必要人工覆盖记录独立，原自动事实不修改。刷新就绪后仍必须单独勾选最终接受，刷新再次清空勾选。

未派发只能明确关闭；已派发有理由撤销后没有Release／ABORTED或物理清理完成记录，数据保留。损坏待核实存储阻止新动作，用户核对后清除；21项准备20／1分页及返回，撤权后页面依据／原准备／历史清空。REPLACE／PRESERVE_MIGRATE的显示和替换命令用例是明确浏览器响应夹具，验证固定来源、迁移材料和独立确认，不视为正式后继候选、真实替换决定或物理迁移流程。桌面及390px截图已实际查看，无横向溢出；原准备页的固定Worker往返预算、实际耗时和降权／恢复／撤权重新计算均有记录。

20项原准备HTTP读取本地采样由约80.97秒降至3.92秒，固定3次Worker往返；原／新profile及字节记录保留。这是本轮开发采样，不是生产性能承诺。

## 失败及边界

首轮TypeScript发现load的默认操作ID推导过窄，显式标注已验证URL参数使用的string可选类型。首轮Edge第二次准备在异步提交完成前读取旧成功提示，导致测试错误地拿到已关闭操作；改为等待本次POST回执及原操作显示。分页首轮返回上一页超时保留原日志，后续验证包含准确分页响应与显示核对，不以放宽产品请求超时替代检查。两份失败时源字节与首轮输入记录一致，首轮和第二轮浏览器失败后显式停止，原TAP不完整、不是最终通过依据；停止范围及退出核实见interruption.json和interruption-02.json。第二轮的最终确认关闭／关闭准备等待超时及21项准备设置超时均保留；没有将主机满载当作已经证明的唯一原因。受控后端在截图后独立更新同一原proof的健康观察，页面GET不更新健康、30秒就绪有效期和15秒HTTP超时均未放宽。关闭用例核对本次HTTP回执并显式刷新，最终DOM／请求错误另存原记录；分页夹具改用真实Worker持久化21个原准备，HTTP创建关闭仍由独立接口组验证，浏览器通过实际HTTP分页。首次每页复用候选basis仍有逐条RPC及资格重算：HTTP计时20项80.97秒，第三次浏览器因此提前停止。新私有Worker方法在同一同步事务内形成整页投影，同一原主体和完整固定依据／epoch／来源资格仅页内复用，不跨请求；响应前复核成员及未配置committer关闭canCommit。新增固定Worker往返预算与降权／恢复／撤权断言。早期仅MJS测试改动的评估保留历史，不作为最终例外；整页投影修正后完整重建及各组回归。扩展接受组的两项v38迁移用例随后暴露历史夹具问题：v37调用当前写门API，依赖v43才存在的business_pending_writes视图。保留失败原日志和测试原字节，单独修正该测试为v37历史SQL建立OPEN／UNKNOWN／CLOSED及事件，迁移后旧版本写门直接按真实表投影；不添加未来视图、不改迁移、不关闭约束、不删断言。3项定向复测通过，最终Lint／Edge重跑。原扩展组仍标记整体失败（52通过2失败），只选其前四文件51个通过用例，所有权3项仅计最终复测，不重复计数；入口／回归／构建等仅这份未加载的独立MJS测试存在SHA差异，精确旧／新哈希和本地MJS导入闭包记录在final-binding，生产输入逐字节不变；运行中未编辑源码或构建；所有失败／中间成功记录保留，不声明完整旧checkout或完整pnpm check已执行。HTTP分页用例首次21轮HTTP设置超时保留，改为一组真实HTTP建立／关闭和20组真实Worker原准备设置，仍通过实际HTTP验证20／1、游标及权限，原300秒用例限制不变；设置进度及分页耗时另留history-profile记录。具体执行、输入指纹和最终选择见原始记录。

同一Codex Agent开发复核，无独立人员或真实用户签认。真实React／Edge／HTTP、Worker／CAS材料预检和T5；源码、镜像、Runner／物理fences／健康及人工审查观察为明确协议夹具，浏览器身份为可信测试注入。没有企业OIDC／Cookie登录、默认准备advance消费、真实Linux／gVisor、正式正向后继保留／替换、完整工作台或产品验收。正式P1-07仍未满足P1-06／G0，未认领；完整4.1／4.3／5.1／5.2和OpenSpec8/13、G0～G4保持原状态，不归档。
