- 同版本发布制品的部分 Cordis／Loader／Include 源码与参考 commit 不同，改用完整受控源码并独立编译；继承修订日志、许可证及逐文件哈希已保存，参考仓库未被改写。

- 本机旧全局 pnpm 会在嵌套脚本中被命中；将精确 pnpm 作为本地工具依赖固定，两端工具检查确认实际生效为 11.28.5。
- tsdown 实际输出 `.mjs`／`.d.mts`；运行入口与 exports 按真实输出配置并通过构建产物测试。没有使用空成功脚本。
- 预构建 `node-addon-require-builtin@0.1.9` 在 Windows x64 与 Linux x64 glibc 实际加载成功。没有在本轮编译其 C++ 源码；其他 OS／arch、Electron 及源码构建环境未验证。
