# P1-08 输入区精简开发复核

2026-11-17，用户确认精简建议后授权实施。实现和开发复核均为本轮Codex，同一Agent，不冒充独立人员或产品／阶段验收。

默认输入区移除附件格式限额长说明、上传记录折叠入口、创建前项目名和正常草稿保存提示。附件说明改为添加附件的title和aria-describedby；上传记录通过“更多 → 附件管理”对话框核实、复用及明确释放，复用成功返回输入，手机从项目导航打开管理后主区域可见。正常保存静默，测试直接核实IndexedDB持久正文；失败／冲突、内存文件、未知上传和原提交恢复继续显式显示。

默认项目名沿用服务端需求前40字／空正文“新项目”，创建后项目标题旁可更名。新增PUT /projects/:projectId/name和准确InputOperation契约、PROJECT_NAME_CHANGED错误；既有操作表事务完成previousName比较、原键幂等及授权复核。只修改name／updated_at，不修改project／Run版本和执行依据，没有迁移或依赖更新。浏览器先在按主体／项目隔离的sessionStorage保存原键／正文，再发送；丢ACK刷新零PUT，明确原键重试只产生一次更名。
