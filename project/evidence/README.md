# 验证证据

此目录保存工作包或阶段门槛的实际验证记录。以实际工作包子目录中的摘要、报告和原始输出为准，管理初始化记录不能替代应用验证。

建议命名 `P0-01-YYYYMMDD.md`、`G0-YYYYMMDD.md`；从 [模板](../templates/验收记录.md) 复制填写。台账 `evidence` 引用这些记录或可访问的 HTTPS 制品链接。

记录需包含固定提交版本、真实环境、执行命令、结果、失败与未执行项、原始报告位置／摘要／校验值、复核结论。大报告与运行产物存放在制品存储或明确保留的本地路径，仓库内保留可复查的 manifest；本机绝对路径须注明适用机器，不能当成跨机器可用的制品地址。

不要提交 token、密钥、数据库、完整用户会话或未脱敏日志。Git 不会因为扩展名为 JSON／JSONL 就自动判断是否包含秘密；提交前核对具体内容。
