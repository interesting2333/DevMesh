## Context
对话、项目、Run和原操作有独立身份；不能通过清除侧栏或级联删除破坏审计与后台任务控制。

## Goals / Non-Goals
提供可核实、能恢复原请求的任务删除。物理清除项目／代码／成果、批量删除、回收站与自动取消运行不在本次范围。

## Decisions
- 新增deleted_at作为会话删除标记，列表／详情／输入／控制／运行时扫描不再包含已删除对话；原消息和操作保留。
- 删除状态投影只读且原子；写入独立检查owner及成员写权限、会话revision、非活动／无未知主轮次、Run暂停或结束、执行和准备效果收尾。
- 原键重放重新授权；删除后的原操作查询可核对主体、会话及当前成员，不恢复会话写入能力。
- 新删除命令复用本机controls日记，以DELETE区分，不污染rename／confirm／旧控制恢复；刷新仅读取，显式恢复先查原键。
- 确认明确数据保留范围。切换删除其他任务时保留当前草稿，删除当前任务后返回新任务入口。

## Risks / Trade-offs
删除是对话移除，关联项目和执行记录仍保留。运行中不能直接删除，需要先打开并暂停或核实。防止隐藏继续运行和未知结果。

## Migration Plan
56→57新增可空列和可见列表索引；不修改已部署55／56。构建和隔离升级／事务／浏览器验证后优雅重启本机服务，保留自动升级备份，不操作真实用户删除。
