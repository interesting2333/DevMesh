## Context

P3-06 要求备份恢复与根目录迁移。恢复需要目标环境与停机窗口；先实现源端一致性快照与完整性校验。

## Goals / Non-Goals

**Goals**
- 生成包含已提交 WAL 状态的一致性 SQLite 快照。
- 拒绝重叠路径与不存在的目录。
- 返回可复核的 SHA-256、字节数与路径。

**Non-Goals**
- 不实现恢复、根目录迁移、加密或远程制品上传。
- 不自动清理旧备份。
- 不执行 T22／T23 或目标环境演练。

## Decisions

1. **VACUUM INTO**：在同一 Worker 连接内执行，得到一致快照；不使用文件复制。
2. **路径校验**：目标目录必须绝对、存在且与数据库目录不重叠。
3. **完整性**：生成后打开副本执行 `quick_check` 与 `foreign_key_check`；失败删除副本并报错。
4. **摘要**：返回文件 SHA-256 与字节数，不返回内容。
5. **后续**：恢复与根目录迁移单独实现并由人工演练。

## Risks / Trade-offs

- VACUUM INTO 需要临时磁盘空间 → 失败明确报错，不假报成功。
- 没有加密 → 备份文件按普通本地材料保护，不宣称满足密钥托管要求。

## Migration Plan

无 schema 迁移；回退删除命令即可。
