## ADDED Requirements

### Requirement: 管理员手工配置 MCP 服务

系统 SHALL 允许部署指定的管理员录入连接、验证凭据、发现工具并保存授权范围。服务配置 SHALL 持久保存在本机，凭据通过部署环境解析。

#### Scenario: 发现并保存

- **WHEN** 管理员提交与部署策略绑定的 Endpoint 和凭据引用
- **THEN** 系统可发现工具并返回目录快照，管理员可以勾选获准的只读工具

#### Scenario: 在服务列表启用或停用

- **WHEN** 管理员切换服务列表中已有连接的开关
- **THEN** 系统保留连接配置。停用立即阻止新调用，启用需通过连接和授权校验并在重启后生效
- **AND** 页面保留在列表。启用校验失败时，开关保持关闭并显示原因

#### Scenario: 管理本机 Playwright MCP

- **WHEN** 管理员在本机预览的 MCP 设置添加或编辑 Playwright MCP
- **THEN** 系统保存服务名称、浏览器和无头运行选项
- **AND** 列表开关直接启停 MCP 进程，完成握手、工具发现和浏览器启动后显示运行中

- **AND** 设置项只展示服务状态和管理操作

### Requirement: 工作流使用已授权连接

系统 SHALL 在工作流工具调用时校验连接快照、角色授权、执行许可和资源范围。

#### Scenario: 工具目录或服务授权发生变化

- **WHEN** 已启用连接的目录哈希变化，或管理员停用服务
- **THEN** 系统阻止发起新的工具调用，并显示需要重新确认或已停用
