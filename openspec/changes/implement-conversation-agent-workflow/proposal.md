## Why

用户确认 project/plans/2026-11-18-conversation-agent-workflow-plan.md 并要求实施。当前首页链路直接进入结构化需求与计划，缺少持续助手回复、咨询分流、会话执行与任务授权。父工作包 P1-08，依赖增量涉及 P0-02／04／06、P1-01／02／03／07、P2-01／08。正式工作包与门槛依实际证据维护。

## What Changes

- 稳定会话、双方消息、主助手轮次、准确动作身份、执行授权和原请求恢复。
- 主助手以目标驱动选择回答、澄清、专业准备、调度或控制，复用现有四角色／A2A／MCP／Run。
- 执行和计划两种模式；执行授权与具体计划人工确认分别记录，质量和权限准入保持。
- 连续对话、可收起执行详情、执行中补充／纠偏、真实能力反馈及准确交付。
